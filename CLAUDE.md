# Food

A static single-page recipe app. Recipe data lives in `recipes/` as JSON, step illustrations in `img/` as SVG. The original reference pages are in `orig/` (Japanese; the site itself is English only).

## Commit message rules

- Single line only — no body, no trailers.
- Keep it short (under ~60 characters) and in the imperative mood: "Add pork bowl recipe", not "Added" or "Adds".
- No prefixes like `feat:`/`fix:`, no emoji, no issue references.
- Commit and push to `main` whenever a meaningful unit of work is complete.
